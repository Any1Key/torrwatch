# Плагины

На Фазе 0 tracker-плагины ещё не загружаются и сетевые запросы к трекерам не
выполняются. Фаза 3 введёт типизированный plugin contract, manifests,
изолированный context и загрузку built-in и явно включённых trusted plugins из
`/data/plugins`.

Плагины не будут получать прямой доступ к базе, torrent clients, уведомлениям,
shell или самостоятельному HTTP-клиенту.
